# BRAND_GUIDELINES.md

## Direction: The Listening Archive
A premium audio-mastering studio crossed with a knowledge archive. Calm, precise, human-crafted.

## Colour
| Token | Hex | Use |
|---|---|---|
| Obsidian | `#08090A` | Dominant background |
| Graphite | `#25292D` | Secondary text on light, large mark ghosting |
| Chalk | `#FFFFFF` | Primary text on dark, primary button |
| Archive | `#F2F0EA` | Light-section background |
| Aluminium | `#B7BEC3` | Secondary text on dark, hairlines |
| Signal | `#D39A68` | Reserved: active playhead, selected citation, recording state, hover on primary CTA |

Contrast notes: Signal is never used for text on Archive (too low). On light sections muted text uses Graphite at 82%. Focus outlines are Signal on dark and Obsidian on light.

## Typography
- **General Sans** (400/500/600): display and interface.
- **IBM Plex Mono** (400/500): timestamps, file names, status, metadata only.
- No italics, no decorative accent words, no tracked all-caps labels.

## Mark and mascot: Dolff
A dolphin in profile wearing round spectacles; the lens is the recognisable detail (Signal pupil). Drawn as SVG in `src/components/Logo.tsx`. The wordmark is "MeetDolff" in General Sans 500 with tight tracking.

Where Dolff appears: nav and footer (brand), the loader (identity reveal), the final CTA (large ghost), the changelog and 404 empty states. Dolff does **not** appear in feature sections.

**Honest note:** no existing brand assets were available to inspect, so the mark is an original construction. Replace with the official asset if one exists.

## Voice
Short, specific, confident sentences. State limits plainly. No "revolutionize", no statistics we can't source, no testimonials.

Core line: *Meetings end. The memory doesn't.*
