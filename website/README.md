# MeetDolff website

Marketing site for MeetDolff. Vite + React + TypeScript + Tailwind 4, GSAP, Three.js.

```
npm install
npm run dev      # develop
npm run build    # emits a single dist/index.html
```

Routes use hash URLs (`/#/product`) because the build is one static file.
Release configuration (Chrome Web Store URL, early-access endpoint, contact, version): see `.env.example` and `WEBSITE_ARCHITECTURE.md`.
Documentation: WEBSITE_RESEARCH, BRAND_GUIDELINES, DESIGN_SYSTEM, WEBSITE_ARCHITECTURE, CONTENT_MAP, INTERACTIONS, ASSET_MANIFEST, TESTING, PERFORMANCE (all `.md` at the repo root).
